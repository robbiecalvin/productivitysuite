Read [CODEX_HANDOFF.md](CODEX_HANDOFF.md) for environment setup and historical results. Evaluate generated applications against explicit contracts and independently reviewed acceptance tests. Run in a disposable environment, retain failure evidence, bound repair attempts and never relax assertions to obtain a pass. Verify local model connectivity and desktop preview separately. Record the model, revision, environment, commands, outcomes and limitations. Historical results are not current verification.
